# 📝 OMR Sheet Scanner & Auto-Grader App

سیستەمێکی زیرەک و هاوچەرخ بۆ پێوانەکردن و چێککردنی بەپەلەی وەڵامەکانی خوێندکاران بە بەکارهێنانی کامێرا.

## 🚀 تایبەتمەندییەکان
- 📷 پشتگیری کامێرای ڕاستەوخۆ یان بارکردنی وێنەی فۆرمی وەڵامەکان.
- ⚙️ ڕێکخستنی ژمارەی پرسیارەکان، بژاردەکان (A, B, C, D) و ئاراستەکان.
- 💯 هەژمارکردنی ئۆتۆماتیکی نمرەی خوێندکار بە خێرایی بەرز.
- 🎨 ڕووکارێکی زۆر جوان و بەکارهێنانی ئاسان لەسەر مۆبایل و کۆمپیوتەر.
